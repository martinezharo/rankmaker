# Commercial SEO-tool crawlers. They index the site to sell backlink and
# keyword data to their own subscribers — they send no visitors and their
# crawling is not what gets rankings shared. SemrushBot alone was 60% of the
# traffic reaching the Worker when this was measured (2026-09-11).
#
# These are asked, not blocked: they honour robots.txt, and a Worker-side
# block costs an invocation to serve the 403. SERankingBacklinksBot is the
# exception — it is in src/lib/crawlers.ts as well because it ignored this.
User-agent: SERankingBacklinksBot
Disallow: /

User-agent: SemrushBot
Disallow: /

User-agent: AhrefsBot
Disallow: /

User-agent: DotBot
Disallow: /

User-agent: MJ12bot
Disallow: /

User-agent: BLEXBot
Disallow: /

User-agent: Barkrowler
Disallow: /

# Search engines are welcome: discovery is the point. Cloudflare injects its
# own managed section above this one, which carries the content signals and
# the opt-out list for AI training crawlers.
#
# /api/ is the exception. It answers the app's own JavaScript with JSON, so
# nothing under it can be a search result, but crawlers execute the page and
# queue the fetch() targets and the sign-in link anyway: Googlebot spent about
# 970 requests there over 14 days (measured 2026-09-18), 53 of them starting an
# OAuth flow it can never finish. Every one is a Worker invocation serving a
# bot. Longest-match wins, so this overrides the Allow above for /api/ only.
#
# The per-locale lines cover the paths the i18n prefix used to alias. The
# middleware now 404s those instead of rewriting them, but a 404 still costs
# the invocation this file exists to avoid, so they are still asked to stay
# out. Matching is literal, so every locale needs its own line — crawlers.test
# .ts derives the list from src/i18n/config.ts and fails if one goes missing.
User-agent: *
Allow: /
Disallow: /api/
Disallow: /es/api/
Disallow: /fr/api/
Disallow: /zh/api/
Disallow: /ms/api/
Disallow: /de/api/
Disallow: /pt/api/
